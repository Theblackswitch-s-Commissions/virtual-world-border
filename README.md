# 📝Pack Explanation:
This is a datapack I've made as a comission for Choco.

This datapack creates a virtual world border by limiting players and teleporting them back when they go too far.

The world border is configurable for each dimension using the following commands:
```mcfunction
scoreboard players set #overworld vwb.dist 8000
scoreboard players set #nether vwb.dist 8000
scoreboard players set #end vwb.dist 8000
```
You can replace the 8000 with any value. This will be the distance in blocks from the center.

If you want to quickly read the current worldborder distance, you can use the following command:
```mcfunction
function vwb:get
```
